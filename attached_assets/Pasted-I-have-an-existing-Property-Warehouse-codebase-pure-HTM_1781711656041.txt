## DESIGN RULES
- Match the existing Property Warehouse design system exactly:
  - Fonts: Manrope (body), Playfair Display / Cormorant Garamond (headings)
  - Dark navy: #0a1628
  - Gold accent: #c9a84c
  - Border radius: consistent with existing cards (12px–16px)
  - Transitions: 0.2s–0.3s ease
- All new CSS must NOT conflict with existing styles — prefix every new
  class with pw- (e.g. pw-bubble, pw-inquiry-card, pw-chat-panel)
- Mobile responsive:
  - Feedback panel: on screens below 480px, panel should be full width
    minus 32px margin, still anchored bottom-right
  - Inline chatbox: full width of the listing card on mobile
  - WhatsApp and inquiry buttons: stack vertically on mobile, side by side
    on desktop
- No external libraries — vanilla JS only
- No backend calls — everything is localStorage
- Do not break any existing functionality. The existing search, filters,
  auth flow, and listing creation must all still work after your changes.
